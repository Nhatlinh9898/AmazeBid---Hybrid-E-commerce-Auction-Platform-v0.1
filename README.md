# AmazeBid - Hybrid E-commerce Auction Platform

A comprehensive e-commerce platform combining traditional auctions with AI-powered features for an enhanced shopping experience.

## ✨ Key Features

- 🤖 **AI Banner Generator** - Create stunning seasonal banners with Gemini AI
- 🎯 **Smart Product Search** - Visual and text-based search
- 🛒 **Multi-format Selling** - Auctions, fixed price, and live streaming
- 🎨 **Seasonal Themes** - Automatic banner updates for holidays
- 💬 **AI Assistant** - Gemini-powered shopping recommendations
- 📱 **Responsive Design** - Works on all devices

## 🚀 Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```bash
   npm install
   ```

2. Set up environment variables:
   ```bash
   cp .env.example .env.local
   # Edit .env.local and add your Gemini API key
   GEMINI_API_KEY=your_gemini_api_key_here
   ```

3. Run the app:
   ```bash
   npm run dev
   ```

## 🎨 AI Banner Generator

Create professional banners automatically with AI:

- **Seasonal Themes**: Tết, Valentine, Christmas, Black Friday, and more
- **Style Options**: Traditional, Modern, Minimalist, Vibrant
- **Custom Elements**: Add your own design elements and colors
- **Auto-generation**: Banners update automatically with season changes

### Getting Gemini API Key

1. Visit [Google AI Studio](https://makersuite.google.com/app/apikey)
2. Create a new API key
3. Add it to your `.env.local` file

## 📱 Usage

- **Browse Products**: Scroll through available items
- **Create Banners**: Use AI Banner Generator in the menu
- **Place Bids**: Participate in auctions
- **Live Streaming**: Host or watch live product demos
- **Visual Search**: Upload images to find similar products
